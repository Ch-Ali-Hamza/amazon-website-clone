# Amazon Website Clone

A beginner-friendly HTML5 and CSS3 practice project featuring a desktop frontend UI clone of the Amazon homepage. This repository was created for learning, layout practice, and mastering modern CSS positioning and flexbox design techniques.

---

## 📌 Project Overview

This project replicates key visual sections of the Amazon homepage desktop view, including the top navigation bar, sub-header menu, hero banner area, product category grid boxes, and full footer.

> **Disclaimer:** This project is strictly created for educational and practice purposes. It is an independent UI implementation and is **not affiliated with, maintained, sponsored, or endorsed by Amazon.com, Inc. or any of its affiliates.**

---

## ✨ Features

The clone implements the following UI components:

- **Top Navigation Bar:**
  - Amazon brand logo display
  - "Deliver to" location selector element
  - Custom search bar with category dropdown and search icon
  - Account Sign-In, Returns & Orders, and Cart visual indicators
- **Sub-Header Navigation Panel:**
  - Sidebar toggle option ("All")
  - Quick link shortcuts (Today's Deals, Customer Service, Registry, Gift Cards, Sell)
  - Promotional deal callout
- **Hero Section:**
  - Full-width hero background image banner
  - Country delivery notification message banner
- **Product Category Grid (8 Boxes):**
  - 8 distinct product category cards (Fashion, Grade Deals, Pants for Men, Wireless Tech, Beauty Routine, Electronics, Home Arrivals, Home Essentials)
  - Interactive "See More" category links
- **Multi-Tiered Footer:**
  - "Back to Top" navigation strip
  - Quad-column information and support links section
  - Centered brand logo separator strip
  - Legal links & educational disclaimer footer

---

## 🛠️ Technologies Used

- **HTML5:** Semantic markup structure
- **CSS3:** Custom styles, Flexbox layout, CSS background images, and custom styling
- **Font Awesome (v7 CDN):** Vector icons for search, navigation, location, menu, and shopping cart icons

## 🚀 How to Run Locally

Since this is a lightweight static web project built with HTML and CSS, no build steps or external dependencies are required.

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git
   ```
2. **Navigate to the Project Directory:**
   ```bash
   cd YOUR-REPOSITORY-NAME
   ```
3. **Open the Project:**
   - Double-click `project1.html` to open it directly in any web browser (Chrome, Edge, Firefox, Safari).
   - Alternatively, open the project folder in **VS Code** and use the **Live Server** extension to launch `project1.html`.
